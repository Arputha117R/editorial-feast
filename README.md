# Culinary Canvas

Build a frontend-only modern restaurant website exactly as requested: React/Vite with TypeScript or JavaScript, Tailwind CSS, Framer Motion, Lucide React, and Google Fonts. Use only local/placeholder food imagery, organized so Cloudinary can be added later. Create reusable components and keep all menu content in separate data objects. Sections in order: sticky Navbar, Hero, Featured Menu, About, Menu Preview, Gallery, Reviews, Location/Hours, Footer. Premium Editorial + Cinematic Food visual language: warm cream/off-white, deep charcoal, burnt orange/terracotta, olive/dark green and dark brown; elegant typography, large editorial headings, generous clean spacing, premium food photography, responsive UI. Add subtle/professional Framer Motion: hero image reveal and staggered text, food card hover zoom/lift, horizontal gallery, scroll reveal, subtle parallax, magnetic main CTA desktop only, and smooth menu category transitions. Mobile-first, fully responsive, smooth scrolling, accessible, fast, with clear Explore Menu and Reserve Table CTAs. Strictly no backend, database, auth, payment, APIs, or admin panel. Keep it clean and production-ready.
